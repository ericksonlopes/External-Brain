# 🧠 External Brain

## O que é este repositório?

Este repositório é um **"Cérebro Externo"** (External Brain) - um sistema de gestão de conhecimento pessoal organizado como um vault do [Obsidian](https://obsidian.md/). É uma coleção estruturada de notas, tutoriais, referências e documentação sobre diversos tópicos relacionados à tecnologia e programação.

## 📋 Conceito de External Brain

Um External Brain é um método de organização do conhecimento que visa:
- **Centralizar informações** importantes em um local acessível
- **Conectar conceitos** através de links e referências cruzadas
- **Facilitar a recuperação** de informações quando necessário
- **Acelerar o aprendizado** através de documentação estruturada
- **Servir como referência rápida** para implementações futuras

## 🗂️ Estrutura do Repositório

### 📁 Principais Diretórios

#### **Programação/**
Contém documentação e tutoriais sobre diversas tecnologias de programação:

- **Python/** - Decorators, PEP8, Pipenv, trabalho com datas, filas (queue)
- **FastAPI/** - Framework web Python
- **Docker/** - Containerização
- **Git/** - Controle de versão
- **Algoritmos/** - Estruturas de dados e algoritmos
- **Design Patterns/** - Padrões de projeto
- **Bases de Dados:** MongoDB, CosmosDB, Redis, SQLAlchemy
- **Cloud/Big Data:** PySpark, ElasticSearch
- **AI/ML:** OpenAI, LangChain, LangGraph, CrewAI, scikit-learn
- **Automação:** Selenium, Airflow
- **Interface:** Streamlit
- **Outros:** Pydantic, PyTube, WAHA

#### **Linux/**
- Comandos e tutoriais relacionados ao sistema operacional Linux
- Exemplo: "Obtendo Estrutura de Pastas no terminal linux.md"

#### **Componentes computador/**
- **Componentes.md** - Lista detalhada de componentes de hardware com preços e especificações
- **Periféricos.md** - Informações sobre periféricos de computador

### 📄 Arquivos de Utilidade

- **LINKS PARA VER.md** - Lista de links úteis para consulta
- **Prompt para criação.md** - Templates para criação de conteúdo
- **badge.md** - Informações sobre badges/emblemas
- **classes.drawio** - Diagramas de classes

## 🛠️ Como Usar

### Com Obsidian (Recomendado)
1. Clone este repositório
2. Abra o Obsidian
3. Abra o vault apontando para a pasta clonada
4. Explore as conexões entre as notas usando o graph view

### Como Repositório Git
1. Clone o repositório: `git clone https://github.com/ericksonlopes/External-Brain.git`
2. Navegue pelas pastas e arquivos markdown
3. Use qualquer editor de markdown para visualizar/editar
